9. Are there more reviews with the word "love" or with the word "hate" in them?

	Answer: 'love' more than 'hate'

	
	SQL code used to arrive at answer:
select word, count(*) as count
from (select 
    case
        when lower(text) like '%love%' then 'love'
        when lower(text) like '%hate%' then 'hate'
        ELSE 'other'
     end word
     from review 
    )
group by word
order by count asc

ii. Difference 2:
         Opend businesses have a little bit more avgStars than closed(3.68 > 3.52) so I think closed businesses have a little bit worse service.
         
         
SQL code used for analysis:
select case
        when is_open = 1 then '+'
        else '-'
        end
    status, count(distinct (id)) as noBusiness,
    round(avg (stars), 2) as avgStars
from business 
group by is_open
